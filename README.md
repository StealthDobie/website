# StealthDobie website

The single-page home for StealthDobie, built with Next.js and designed for Vercel.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run lint
npm run build
```

## Deploy to Vercel

Import `StealthDobie/website` into Vercel and keep the detected Next.js settings. No environment variables are required. When a custom domain is attached, set `NEXT_PUBLIC_SITE_URL` to its full canonical HTTPS URL so social metadata uses that origin.

## Artwork

`public/stealthdobie-emblem.png`, `public/dobermann-wordmark.png`, and `public/og.png` are original pixel artwork generated for this project from the supplied Dobermann subject reference. The final assets contain no copied game logo, character, typography, or publisher mark. The navigation icons are custom 16×16 SVG pixel art drawn in the page source.
